# Trabajo con Git

Estas reglas orientan las operaciones sobre el repositorio cuando se utiliza Git.

- Antes de realizar cambios u operaciones Git, se DEBEN inspeccionar la rama actual, el estado del repositorio y los cambios locales, identificando las protecciones aplicables y el trabajo que deba preservarse.
- Nunca se DEBE trabajar destructivamente sobre ramas protegidas.
- Los commits se DEBEN mantener coherentes, con cambios relacionados y una descripción que represente su contenido.
- No se DEBE mezclar trabajo no relacionado ni incluir cambios ajenos al alcance de la tarea.
- No se DEBE forzar un push ni reescribir historia salvo instrucción explícita. Esa instrucción no habilita operaciones destructivas sobre ramas protegidas.

Los nombres de ramas y los mecanismos de entrega corresponden al contexto del proyecto; estas reglas no los prescriben.
